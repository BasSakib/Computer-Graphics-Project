# Doraemon's Treat Hunt 🎮

A 2D interactive game developed using C++, OpenGL, and GLUT for the Computer Graphics course at American International University-Bangladesh (AIUB).

## Features
- Three difficulty levels.
- Doraemon running and jumping animations.
- Doracake and heart collection system.
- Multiple obstacles and collision detection.
- Scrolling 2D environment.
- Background music.

## Technologies
- C++
- OpenGL
- GLUT
- Code::Blocks

## How to Run
1. Download or clone this repository.
2. Open `Doraemon_Treat_Hunt.cbp` in Code::Blocks.
3. Configure OpenGL, GLUT, and the Windows multimedia library (`winmm`).
4. Ensure `sound.wav` is in the executable's working directory.
5. Build and run the project.
